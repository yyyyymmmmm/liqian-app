# 礼钱账本 · 图标第二轮迭代：只改「礼」字字形（rev2）

日期：2026-11-07。触发反馈（用户原话）：「礼字太正了，支付宝不板正！」——支付宝的「支」是定制字：带前倾动势、笔画有提按与飞白、活而不板；现稿两稿的礼字都偏印刷体式「立正」。
本轮纪律：**B、D2 两稿的构图、配色、结构一律不动**（仍为生成概念稿，品牌色校准留生产定版时做，口径同 CANDIDATES.md），只重写其中的「礼」字。做法为逐稿改图（以现稿为底重绘字形），避免构图漂移。

本目录新增文件：`candidate-b-seal-rev2-1024.png`、`candidate-b-seal-rev2b-1024.png`、`candidate-d2-frame-rev2-1024.png`、`candidate-d2-frame-rev2b-1024.png`（均 1024×1024 满幅）；验稿 `check-sheet-rev2.png`（原稿两行对照＋四张 rev2，各 180/60/40/40 灰度）与单项 `check-40-gray-*-rev2*.png`。

## B 印章（墨底＋朱砂印＋白文礼）——字是印面阴刻白文

### B rev2 · 全行书势 `candidate-b-seal-rev2-1024.png`
- **笔势**：半草行书。点画化作一记向右下甩出的飞点；礻的横、撇、竖提被笔势连成一气，笔画交接处不抬笔、以牵丝带过；右部竖钩是全字的主势——自上而下加速、到底部向左铺开再上挑收锋，像一笔写到底的一口气。
- **倾斜/连带**：整字重心右移、微微右上扬，左低右高的动势最接近支付宝「支」那种前倾感；连带最强，礻的内部结构已融进流势里。
- **40px 结论**：通过。40 彩色与 40 灰度下白文轮廓完整、仍读作「礼」，靠的是「点＋左势＋大钩底」的整体剪影；但必须如实说：它认的是**势**不是**画**——礻的笔画细节在小尺寸下不可分辨，初次见者辨认速度会慢于 rev2b。

### B rev2b · 半行书、笔画分明 `candidate-b-seal-rev2b-1024.png`
- **笔势**：行楷偏行书。顶点击实分明；礻的横撇起笔带回锋、中段提按出粗细，竖提与撇各自收尾、不相融；右部竖钩粗壮下行、底端横扫后尖锋上挑，全字最有力的一笔。
- **倾斜/连带**：仍有微微右上扬与笔断意连的节奏（笔画之间靠呼应不靠粘连），比 rev2 收一档、比原稿活一档。
- **40px 结论**：四张 rev2 里小尺寸最稳的一张。40 灰度下点、礻、钩三部分各就其位，「礼」无歧义。

## D2 版框（纸白＋双线版框＋墨字礼＋右下小印）——字是框内正文

### D2 rev2 · 狂草飞白 `candidate-d2-frame-rev2-1024.png`
- **笔势**：行书放到最大。粗笔触全程带飞白，左撇一挥到底、与横画粘连成势；右部竖钩下行后横扫，收尾甩出一簇上挑的散锋。
- **倾斜/连带**：字势最野，整字明显左倾下压再向右上挑出，动感是四张里最强的；代价是礻已半草化、钩尾的散锋在大图上略显毛糙。
- **40px 结论**：勉强通过。40 下仍是「礼」，40 灰度靠墨块分布认字；飞白在小尺寸下全部失效、只剩噪音感，它是大图气质稿，不是小尺寸稿。

### D2 rev2b · 受控行楷 `candidate-d2-frame-rev2b-1024.png`
- **笔势**：行楷。点画饱满如悬针起势；礻结构完整分明（横、撇、竖提、点提各归其位），长撇舒展出锋；飞白只留长撇一处、其余笔画实墨；右部竖钩一笔直下、底部圆转横扫、末端轻巧上挑，干净利落。
- **倾斜/连带**：整字略向右上扬，笔画间以呼应相连（提按节奏代替牵丝），是「写得快但没连笔」的手写感。
- **40px 结论**：D2 两稿里明显更好。40 与 40 灰度下结构清爽、「礼」一眼可认，飞白退为质感不抢识别。

## 推荐

**两稿都推 rev2b 版**，理由一致：用户要的是「不板正」，不是「认不出」。rev2b 把动势做进提按、倾斜和收锋里——点是甩出来的、撇是扫出去的、钩是挑起来的——但每一画都还在原位，40px 灰度下无歧义；这正是支付宝「支」的真实做法（它的活全在字形定制上，结构本身从不含糊）。

- 若走 B（印章）：定版用 **B rev2b**；B rev2 留作「更大胆」备选——它势最足，但靠轮廓认字，风险在长辈用户和货架速览场景。
- 若走 D2（版框）：定版用 **D2 rev2b**，无悬念；D2 rev2 的飞白过量，只适合海报/启动图等大尺寸物料，不适合做图标本体。

生产定版时仍需按 CANDIDATES.md 的修正点校准颜色（朱砂 #A62B1F / 纸白 #FAF9F6 / 墨 #262520）、B 稿印面去斑驳，并对选定字形做一次描摹矢量化——生成稿的笔锋边缘在全尺寸集里会被放大，逐字核对字形后再出图。
