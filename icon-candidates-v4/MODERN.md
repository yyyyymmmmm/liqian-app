# 礼钱账本 · 图标第三轮探索：现代方向（M 系列）

日期：2026-11-07。触发反馈（用户原话）：「礼，现在感觉没有跟上时代」。前两轮的语言——印章、版框、书法字——本质是把「传统」越做越精致，用户否的不是执行而是语汇本身。本轮纪律：**彻底换语汇**——不要书法体、不要印章、不要版框、不要任何仿古元素；用当代品牌图标的几何语言重做。方法仍遵循 app-icon skill（含 2026-10-20 质感纠正：扁平＋干净渐变＋粗几何，禁 glossy 3D）与验稿口径（满幅、主体 60–80%、一个焦点、40px 灰度验稿）。

本目录新增文件：定稿概念稿 3 张（`candidate-m1-geometric-1024.png`、`candidate-m2-symbol-1024.png`、`candidate-m3-crop-1024.png`，均 1024×1024 满幅）；初稿留档 3 张（`candidate-m*-draft1-1024.png`）；验稿 `check-sheet-modern.png`（三稿各 180 圆角预览 / 60 / 40 / 40 灰度）与单项 `check-40-gray-m*.png`。

## 一、调研：当代头部 App 怎么处理单字 / 符号图标

- **支付宝（2024 换标）**：去掉外框和全部文字，只剩一个「支」；官方口径是线条更流畅现代、引入立体自然光、如水般通透。关键动作不是加东西，是**把字本身做成几何定制的商标**——笔画等粗化、转角圆润化、结构为屏幕显示优化。单字图标的现代感来自字形工程，不来自装饰。
- **微信支付 / 微信**：符号而非字——气泡、盾牌类粗几何形，填充定义形状，无描边细线；识别靠独有剪影。
- **小宇宙**：星球＋轨道的极简几何符号，一条轨道线就是唯一记忆点；深色底＋单符号，大负空间。
- **Keep**：定制几何字母 K，笔画做切角与加速感处理，是「字标几何化」的运动品类样本。
- **潮汐**：近乎纯色场＋极小符号，克制到只剩氛围——证明现代感可以靠「减」不靠「加」。
- **钱迹（品类内）**：黄色圆形＋号浮钮是其产品内最强符号，图标走简洁几何物件路线；品类里没人靠书法字建立现代感。
- **2024 年国内换标潮的共性**（数英/Digitaling 综述口径）：简约化、动态感、开放性——去框、去文字、线条流畅化是全年主旋律。

**共性提炼（本轮执行标准）**：① 几何构成，字与符号都按网格和圆切线搭出来；② 圆角端点、粗线条，笔画等粗或受控变化；③ 大负空间，元素 ≤2；④ 渐变只做同色系两色微渐变，克制新鲜；⑤ 一个记忆点（一个字 / 一个结 / 一道切分线），其余全部让位；⑥ 没有任何「年代感材质」——无墨迹、无纸纹、无刻痕。

## 二、候选（按推荐序）

### 推荐 1 — M1 几何礼 `candidate-m1-geometric-1024.png`

- **构成逻辑**：把「礼」当 logo 字标重搭——全部笔画等粗、端点全圆头；礻部简化为一条干净的折线骨架（点提并入横撇系统，不再逐画摹写）；乚放大成全字的主钩，一竖到底、底部横扫，负空间在礻与乚之间留出一整块呼吸区。白字压在朱砂→橙红的同色系微渐变满幅底上，字占画面约 70%。
- **与当代同类的对位**：这是支付宝 2024 路线的正面同构——单字、几何定制、去一切装饰。Keep 的几何字标、Cash App 的字母形都是同一家族。**必须如实指出的一点**：它和支付宝的距离回到「结构同构、颜色区分」——第一轮被否的正是这个结构。区别在于：当时的字是书法体（传统语汇＋现代结构，气质打架），这次字是纯几何字标（结构与语汇同代），且朱砂红与支付宝蓝在货架上色相距离足够。选它等于确认「公式可以像，语汇必须新」。
- **40px 结论**：三稿最强。40 彩色与 40 灰度下笔画无粘连、「礼」无歧义，灰度下靠白字对深底的高对比仍完整可读。
- **生产修正点**：①渐变采样偏亮偏橙（左上约 #D61318、右下约 #F66816），已冲出朱砂家族——定版须压回 #A62B1F → #C8451F 一带，降一档明度才有品牌沉稳感；②礻的点画目前并在撇里，矢量重排时可选择保留这个简化（更符号化）或补一记独立圆点（更「礼」），建议保留简化，与乚的大钩形成一简一放的节奏；③字重心略靠下，定版上移约 2% 做光学居中。

### 推荐 2 — M3 大字分块 `candidate-m3-crop-1024.png`

- **构成逻辑**：海报式排版——一条 45° 斜线把画面切成纸白（左上）与朱砂（右下）两块，超大几何「礼」横跨两块并随块反色（纸上墨字、红上白字），字的下半截被斜线「切」出节奏。它不靠容器讲品牌，靠**切分线＋反色**这一道版式动作当记忆点。
- **与当代同类的对位**：对位的是小宇宙/潮汐那一脉的「排版即品牌」和近年的瑞士风海报字标潮流；在国内记账与礼金品类里没有人用斜切分块，货架差异是三稿里最大的。风险也在这：它最不像一个「工具 App」，更像文化品牌——与产品「稳、日常」的定位需要用户自己权衡。
- **40px 结论**：通过。40 下斜线与反色仍在、「礼」可读；40 灰度下斜线两侧靠明度差（纸白 vs 中灰红）依然成立，分块不塌。剪影强度仅次于 M1。
- **如实说明的缺口**：brief 要求字占 120%+ 出血裁切，生成端两轮都没把字真正推出画框——现稿字约 90%、四边完整。构图（分块＋反色）已成立，但「裁切感」未达标；定版须在矢量重排时把字放大到 120% 并向右下移，让乚的钩尾与礻的竖笔切出画框，届时 40px 可读性需再验一轮。
- **生产修正点**：红块采样约 #D82D1E，校准 #A62B1F；纸面采样约 #F8EEE6 略带粉，校准 #FAF9F6；笔画端点现为平切，统一改圆头与 M1 同一字形工程口径。

### 推荐 3 — M2 礼结符号 `candidate-m2-symbol-1024.png`

- **构成逻辑**：不用汉字。取「礼」最后一笔乚的流水势和礼结的交叠结构，抽成两条等粗圆头的朱砂缎带：一穿一绕、中央一个交叠点，右下拖出一条长尾——尾巴的走向就是乚的钩。纸白满幅底、符号占约 60%，全图只有「一个结」这一个记忆点。
- **与当代同类的对位**：微信气泡、小宇宙轨道同一路线——符号剪影建品牌，不依赖文字，国际化与延展性（启动图、空状态、周边）三稿最好。代价同样明确：**首认成本**。新用户第一眼读到的是「结 / 丝带」，读不到「礼 / 记账」，品类信息要靠图标下方的 App 名补齐；且剪影与公益丝带（awareness ribbon）有远亲感，缎带的弧度定版时要再收紧、更几何化以拉开距离。
- **40px 结论**：剪影通过、语义不通过（与第一轮 C 礼封同一类问题：图读得出、意思要猜）。40 与 40 灰度下结形完整、尾巴在，是三稿里灰度形态最优雅的；但它在验稿表里赢的是「形」，输的是「义」。
- **生产修正点**：符号红采样为亮正红（底采样 (246,104,22) 是 M1 的，此稿符号约 #E63329），校准 #A62B1F；尾巴末端的圆头略肿，矢量时收成利落的斜切圆头；整体再放大到约 68% 补足货架存在感。

## 三、验稿记录

`check-sheet-modern.png`：三稿并排 180 圆角预览 / 60 / 40 / 40 灰度。结论：M1 三项全过且最稳，是唯一「形义双过」的；M3 形义双过、输在出血未达标（生产可补）；M2 形过义不过，胜在符号延展性。初稿留档说明：M1 初稿右部误生成闭合方框（读作「祀」的右部），已迭代修正为单钩乚；M2 初稿是三巴式回旋纹（民族纹样感、与礼无关），已迭代为双带交叠结；M3 两稿构图基本一致，迭代只推了字号未达出血，故按现稿交付并在上文标注缺口。

注：三稿均为生成概念稿，品牌色有系统性偏亮（生成端通病），定版时统一校准到朱砂 #A62B1F / 墨 #262520 / 纸白 #FAF9F6，M1 渐变终点放宽至 #C8451F；选定稿需做一次描摹矢量化重排（尤其 M1/M3 共用同一套几何「礼」字形资产），再导出全尺寸集并复验 40px 灰度。

## 四、与前两轮的关系（给决策的一句话）

前两轮回答的是「传统怎么做得高级」，本轮回答的是「当代品牌怎么做」。M1 是把支付宝验证过的单字公式用**当代字形工程**重做一遍；M3 是换成排版品牌路线；M2 是换成符号品牌路线。三稿与 B 印章 / D2 版框之间不是新旧迭代关系，是**品牌路线之争**：选 M 系列即意味着产品视觉整体从「礼谱 / 印章」的仪式叙事，切到「几何 / 排版」的当代叙事——图标先行，App 内的落印、礼谱 PDF 等传统元素是否保留、保留到什么程度，建议在定版时一并定调，避免图标与内页气质打架。
