# v5.0.1 设置页（「我的」）信息架构重组

起因（用户原话）：设置页「分布不行，太杂了，排序感觉也不对」。
病根坐实：现版 7 组 22 行是历次版本逐个往上堆的结果（v2.5 记录组把
数据查看入口与设置混排、v4/v4.5/v5 的新入口各占一组或塞进「关于」），
没有整体信息架构——查看类、数据类、提醒类、偏好类、账号类互相穿插。
本版只重组与排序：**不删任何现有功能入口、不改任何子页内部实现与
跳转目标**；盘点表逐项对照旧位置 → 新位置。

## 二、新结构（定版 IA 落地）

顺序：会员卡（顶）→ 总览 → 数据 → 提醒 → 外观与偏好 → AI 管家 →
协作 → 隐私与协议 → 帮助 → 关于（沉底）。

- **顶部会员卡**：#11 单行成卡置顶（insetGrouped 首块），副标题即
  权益状态，点进仍是 v5 PaywallView，不新造付费墙。
- **总览**：#1–#4。说明见第三节偏差 ①。
- **数据**：#14、#15、#17、#16、#18、#7、#10——同步状态打头、
  导出/恢复居中、回收站随后、示例数据沉底并在副标题首字标「示例」。
- **提醒**：#5、#19（条件行仍只在从未备份/逾期时出现，动作不变）。
- **外观与偏好**：#12、#9、#6、#8；原「礼谱」组页脚（落款说明）与
  「外观」组页脚（主题说明）合并为本组页脚，两段信息都不丢。
- **AI 管家**：#13，AISettingsView 内部原样。
- **协作**：新增直达行「家庭协作」→ 礼簿列表（LedgersView）→
  礼簿详情 → 礼簿班子（LedgerMembersView）。协作本是礼簿级事务、
  设置页此前无入口；此行只做落点，链上全是现有页面、零新造。
  副标题写明路径，免得用户以为点开就是协作页。
- **隐私与协议**：#22、隐私政策（→ LegalView 隐私）、用户协议
  （→ LegalView 协议）——后两者此前藏在 AboutView 子页内，本版
  按 IA 在设置页直达，子页内原行保留不算设置页内重复（见偏差 ②）。
- **帮助**：#21、意见反馈（→ FeedbackMail 邮件链接，右侧显地址，
  与 AboutView 内同一目标）。「给个好评」不设：现版无此入口，
  且 ReviewPrompt 的既定设计是只在正向时刻由系统评分请求出现、
  About 页不放诱导评分文案——不为凑组新造（见偏差 ③）。
- **关于**：#20 沉底，右侧版本号保留；版本详情仍在 AboutView 内。

### 行样式统一
一级行一律 entryLabel（图标 24 宽 ink 色＋标题＋可选副标题）＋
必要的右侧状态值/系统披露箭头；开关行就地开关（iCloud、隐私锁
统一改走 entryLabel 标签，此前隐私锁是自绘 HStack，本版收敛）；
Picker 行同式。分组标题与间距沿用 List(.insetGrouped) 系统度量
与 LiqianMetrics 间距令牌；内容层纸墨平面、零玻璃（定版红线）。

## 三、与定版 IA 的偏差（如实记账）

① **多一组「总览」**：#1–#4 是数据查看入口，经全仓 grep 核实
在全 App 仅设置页一处可达（StatsView/AnnualReportView/
PendingPeopleView/PrepListView 均只被 MeView 引用），删不得；
定版九组无对应落位，故收敛为一组置于会员卡之下。其余九组
结构与顺序严格按定版 IA。
② **隐私/协议/反馈双落点**：设置页直达行（IA 要求）＋ AboutView
子页内原行保留（子页实现不动的硬规矩）——跨页双落点、页内不
重复，子页行不是设置页的重复入口。
③ **「给个好评」缺位**：IA 原文为「现有评分引导入口若有」——
现版确无，且既定设计明确不放常驻评分入口，本版不新增。

## 四、真机待验（未验，不宣称）

1. 设置页从顶滑到底逐组核对：会员卡 → 总览（4）→ 数据（7）→
   提醒 → 外观与偏好（4）→ AI 管家 → 协作 → 隐私与协议（3）→
   帮助（2）→ 关于，顺序与分组和本表一致、无缺行。
2. 每个入口点进去还是原来的页：总览四页、RemindersView、
   RelationsManageView、TrashView、HostNameEditView、
   AppearanceView、AISettingsView、PaywallView、LegalView 两页、
   AboutView 逐个点开返回。
3. 开关就地可用：iCloud 同步开关、隐私锁开关点按状态正确；
   年涨幅 Picker 能改且人物详情口径随之变。
4. 条件行：未登录 iCloud 时「打开系统设置」出现在 iCloud 行下；
   备份逾期时备份提醒行出现在「提醒」组（不在数据组）。
5. 家庭协作行点开是礼簿列表，任选一本进详情能看到「礼簿班子」。
6. 示例礼簿行在数据组底部，生成/清除照常，副标题带「示例」字样。
7. CSV 行 Pro 门控行为不变（机主构建放行直达分享；未开通走付费墙）。
