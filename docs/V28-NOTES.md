# V28-NOTES · 礼谱 PDF 细节专项（v2.8）

依据 LIBU-PDF-SPEC / LIBU-V3-SPEC 增补。范围纪律：只改 PDF 生成
（GiftBookPDF、LibuExportView 的模板谱序）与 Core 的 PDF 专用格式化
（MoneyText 繁体变体、LiqianDate 月日、新增 LibuText）；未动 App 界面
文案与数据模型；未 commit/push。

## 1 逐笔日期（内页）

- Core 新增 `LiqianDate.lunarMonthDay(for:)`：农历月日，如「十月初八」
  「闰四月廿三」（lunarString 去掉「农历」前缀，闰月/跨年沿既有口径）。
- 版面选择：**同日只标首笔**（不用逐笔标、不用分段）。判「首笔」按全册
  成册流序（counted，日期升序）：某日期第一次出现的记录 id 集
  `firstOfDayIDs` 在 makePDF 统一算好传进每个内页，跨页同日不重复标。
- 位置：该列小字（阿拉伯金额·方式）下方，楷体 10.5 小字竖排，生成串经
  LibuText 转繁体字形（如閏四月）。标签是完整月日（「十月初八」）而非
  只有日名——跨月连排时只有日名会撞，月日更稳妥。
- 排序与并列口径不变：日期升序、同日按姓名；同人多笔仍并列多列。

## 2 繁体字表（PDF 专用）

- 落点：固定串直接在 GiftBookPDF 以繁体字面量书写；金额大写在 Core
  `MoneyText.chineseUppercaseTraditional(cents:)`（与简体版共用读法算法，
  只换字表）；程序生成的日期定式串（干支日期/月雅称/农历月日）经新增
  Core `LibuText.traditionalGenerated` 做两字映射（闰→閏、腊→臘）——
  这两个字是 Core 生成串里仅有的简体字形，其余干支/月名/日名繁简同形。
- 繁体大写字表：數字壹貳參肆伍陸柒捌玖、拾佰仟、萬億兆、框架字圓/角/
  分/整/負。例：500 元→「伍佰圓整」。简体版 chineseUppercase 原样不动，
  App 内显示不受影响（有单测互相锁定）。
- 已换繁体的固定串：禮錢賬本·導出（地脚品牌）、謹識（封面/谱序/汇总
  落款后缀）、主家謹識（无落款名时印文）、題字閑章吉語（福壽康寧/
  喬遷之喜/平安喜樂/開業大吉等）、譜序/譜序（續）、第 X 頁、欄題（見
  §3）、彙總/奠儀總計（含續页）、總人數/總筆數/收禮合計/隨禮合計/
  大寫/另有待送出…未計入本譜、按日小計/按關係小計、校對、隨禮（内页
  方向注脚）、補記。
- **用户数据红线**：人名、礼簿名、事由（ledger.type 照原样进封面信息
  列）、方式、关系、备注一律原文输出。代码层面保证：traditionalGenerated
  只作用于 ganzhiFullDate/lunarMonthDay/lunarMonthAlias 的输出（定点调用），
  LibuText 文件头写明禁喂用户数据；繁体化靠字面量与大写生成，不存在对
  用户字段的转换函数。
- 谱序模板（LibuExportView.LibuPreface.template 六篇）：固定正文换繁体
  版；变量（主家名/干支日期/人数）插值点不动，干支日期只过
  traditionalGenerated，主家名不转换。AI 谱序正文是生成内容，照原样
  上谱，不转换（AI 提示词未动）。

## 3 欄題

- 内页版框内顶端居中：红事「賀儀」、白事「奠儀」，楷体 15、主色，与
  版框/鱼尾同页协调；列间线起点下移至欄題下方（contentTop+6）。
- 白事禁賀：grep 自查——GiftBookPDF 中「賀」仅出现在注释与
  `bai ? "奠儀" : "賀儀"` 的红事分支，白事永不绘制；模板谱序中「賀」
  只在乔迁/满月/升学三篇红事模板，白事模板无賀字。

## 4 小计（汇总页）

- 汇总页改流式分页：全部汇总行先组装成行表（总计→按方式→按日小計→
  按關係小計），按版心容量分页，续页页题加「（續）」；校對空行与落款
  双印固定落在最后一个汇总页底部（末页预留 pageH-300 以下不排正文，
  溢出行整体挪续页）。单页情形与旧版版式一致。
- 按日小計：日期（干支全日期，繁体字形）＋笔数＋收/随金额（只数字，
  大写只留总计——汇总页横排版面从简）；按關係小計：关系（记录数据
  原样）＋笔数＋收/随金额。两节均按成册口径（排除待送出）。
- 防重复规则：全谱只有一天时不出按日小計、只有一种关系时不出按關係
  小計（与总计完全重复的节不出）。
- 白事页题与大题用「奠儀總計」，红事「彙總」；总计与大写位置口径不变
  （繁体大写已计入 §2）。

## 5 補記页

- 卷末（汇总之后）固定一页：同纸面同版框、同欄格（8 列列间细线与内页
  同位同式）、页题「補記」居中（与欄題同位）、页眉地脚照常（谱名＋
  魚尾＋「補記」页签＋品牌小字）。无其他文字，供打印后手写补记。

## 6 封面复核

- 日期保持干支年＋农历月日（ganzhiFullDate 生成串转繁体字形），未加
  公历大字；公历仍只在题字左列信息行小字（原有）。
- 封面固定字纳入繁体表：落款謹識、主家印回退印文主家謹識、閑章吉語；
  簿名与事由是用户数据，照原样（§2 红线）。
