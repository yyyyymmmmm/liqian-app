# v3.1 礼谱内页分段题签 · 落实记录

传统礼谱内页按段登记：同一本礼簿的记录按「关系」分段，段与段之间换页
另起，段首出题签。本轮只改内页排版与 Core 分组计算，封面/谱序/汇总/
答谢/補記结构、数据模型均未动。

## 分组计算（Core 新增 LibuSections.swift）

- `LibuSections.groupByRelation(_:relation:)`：泛型纯函数（不碰 SwiftData，
  可单测）。段序按 `LiqianConstants.relations` 枚举序（亲戚/朋友/同事/
  同学/邻居/其他）——与汇总页「按關係小計」完全同口径；枚举外关系附后、
  按字面升序（同小计口径）；关系为空串者归入「其他」。
- 段内保序：保持入参相对顺序。调用方（GiftBookPDF.makePDF）仍按现行成册
  口径先排好（排除待送出、日期升序、同日按姓名），分组不重排段内，
  段内排序即「日期升序、同日姓名」。
- Project.swift 的 sources 是 glob（`Sources/LiqianCore/**`），新文件自动
  收录，无需改工程文件。

## 题签（GiftBookPDF 内页）

- makePDF 改为按段分页：每段从新页起排、段内仍每页 8 列；页码
  （「第 X 頁」）全册连续递增；段的续页页顶**不重复题签**（老谱规矩）。
- 题签只在「段数 > 1」时出现；只有一段时不出（与汇总小计「单组不出」
  同口径，避免空仪式）。空册仍出一页无题签的空白内页（现状不变）。
- 题签位置与样式：欄題（賀儀/奠儀，y=99、楷体 15）之下，y=126、楷体 13、
  主色（红事朱砂/白事素蓝），水平居中；题文两侧各缀一段 30pt 主色细线
  （0.75、alpha 0.6），与版框/列线同语言，字号小于欄題不抢层级。
- 让位：段首页的列线与记录列整体下移 36pt（记录区顶 116 → 152，列线起
  于 158），续页恢复 contentTop。段内逐笔日期（同日只标首笔）、双字名
  间字、金额大写（红事圓整/白事不缀整）等 v2.8/v2.10 口径全部保持；
  firstOfDayIDs 仍按全册日期流序计算，分段不影响其判定。

## 题签文案与笔数（取舍）

- 文案：「繁体关系名 · 汉字笔数筆」，如「親戚 · 拾貳筆」。
- 笔数用**汉字数字**（未用阿拉伯数字）：Core 新增 `LibuText.chineseCount`，
  字表用财务大写数字（壹貳參肆伍陸柒捌玖拾佰仟萬億），读法同 MoneyText
  整数读法（按节、节内零只读一个、节间补零）；账簿计数式起头省「壹」——
  全串以「壹拾」起头时省首字（12 → 拾貳、10 → 拾、100000 → 拾萬），
  与规格示例「拾貳筆」一致。
- 繁体关系名只对系统词表内六个值做字面映射（亲戚→親戚、同学→同學、
  邻居→鄰居，其余繁简同形）。关系是 Picker 选的系统词、非用户自由文本，
  与欄題等固定串同口径；词表外的关系（历史数据原文）**不做繁简转换**，
  照原样出题签，守住「用户数据不转换」红线。

## 随礼口径（对「随礼卷」的落实说明）

现行礼谱**没有独立随礼卷**：随礼与收礼同册登记、逐笔在小字注「隨禮」、
汇总页分开统计（v3 以来口径）。本轮据此落实：分段统一作用于全册成册
记录——每段含该关系的收礼与随礼笔，题签同式，随礼的逐笔标注不变。
若日后决定拆出独立「随礼卷」，只需在 makePDF 里先按 direction 切两批、
各自调用同一分组与分页逻辑即可，本轮的 Core 函数与题签绘制可直接复用。

## 单测（Tests/LiqianCoreTests/LibuSectionTests.swift）

- `LibuSectionGroupingTests`：多关系分组顺序（枚举序＋段内保序）、枚举外
  关系附后、单关系、空记录、空关系归「其他」，共 5 例。
- `LibuChineseCountTests`：笔数汉字数字 14 个断言（0/个位/拾起省壹/整十/
  佰级补零/仟/萬/拾萬）。
