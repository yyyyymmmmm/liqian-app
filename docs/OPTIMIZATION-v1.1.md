# v1.1 优化清单（竞品 + 大厂对照，2026-11-07 实查 App Store 描述）

## 竞品实况

- 礼尚记（头部）：关系详情（总收/总送/差额/待回礼）、事件账本、**备礼清单**
  （提前记要准备的礼+预算+提醒）、统计复盘（年度/关系/事件）、专业版解锁
  Excel/照片附件/多账本/高级统计。
- 礼小记：**大字键盘+常用金额一键输入「三秒记一笔」**、拍照 OCR 纸礼单、
  语音记账、收支趋势图、关系分布、往来排行、iCloud 同步、**农历日期**、
  **Face ID 加锁+后台模糊**。
- 礼记：批量记账、最近联系人补全、自定义事由、联系人智能去重合并、统计大盘。
- 人情账本：收支平衡看板、12 类场景+自定义标签、家庭共享。
- 随手记（大厂记账）：**自定义记账键盘、首页即报表（数据卡片+图表）**、
  流水日历、多人协同+角色权限。

## v1.1 采纳（本地可实现、按价值排序）

1. 三秒记账：记一笔页改大厂记账形态——大号金额显示+常用金额 chips
   （100/200/300/500/800/1000）+自定义大字数字键盘，金额区不用系统小键盘。
2. 首页即报表：礼簿页汇总卡下加「待回礼」提醒卡（有人未回时出现，点进人物）
   + 本年收/随迷你柱状图（Swift Charts）+ 最近往来 5 条。
3. 隐私锁：我的页加 Face ID/指纹解锁开关（LocalAuthentication），开启后
   冷启动与回前台需验证，后台预览模糊。人情数据敏感，竞品有、大厂标配。
4. 统计升级：我的页加往来排行 Top5（按往来总额）+ 关系分布条形图
   （Swift Charts），与既有年度/事由统计并存。
5. 农历日期：礼簿封面与详情在公历日期旁加农历（如「农历十月初八」），
   Calendar(.chinese) 生成；婚丧嫁娶看农历是刚需，竞品有。
6. 备礼清单：待送出在人情页顶部成卡集中展示（数据已有，补入口与说法）。
7. 自定义事由：新建礼簿事由含「自定义」可输入（竞品礼记有）。
8. 顶部留白修复：三页改系统 navigationTitle 大标题，去掉自绘大标题+空顶栏
   （用户真机截图反馈）。

## 明确不采纳（及原因）

- OCR 拍照识别：PRD 定 v1.5，不提前。
- 语音记账：v2 候选。
- iCloud/CloudKit 同步：属账号线（v0.3），不在本地版硬塞。
- 关系图谱：PRD 非目标，对回礼决策帮助有限。
- 联系人自动合并：PRD 红线是「不自动合并」；手动合并进 v1.2 候选。
