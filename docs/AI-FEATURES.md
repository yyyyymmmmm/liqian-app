# AI 功能规范（DeepSeek，用户 2026-11-07 拍板全套上）

## 接入方式（v1 内测口径）
- 用户自备 DeepSeek API Key，在 App「我的 → AI 智能助手」里填写，
  只存本机 Keychain，App 直连 api.deepseek.com（OpenAI 兼容
  /chat/completions，model=deepseek-chat，response_format=json_object）。
- 核心账目永远本地规则计算；AI 只做「理解」与「生成」，结果一律先进
  预览/表单由用户确认后才落库；失败自动回退现有规则解析并明示。
- 每次 AI 调用都是用户当面点按触发；调用前界面明示「将把这段文字发送
  至 DeepSeek 解析」。正式版再评估公司后端代理。

## 三个功能
1. 智能粘贴解析（批量页第三段「AI 解析」）：任意杂乱文本（微信接龙、
   备忘录流水、多人多行）→ JSON 数组 [{name, amountYuan, relation?,
   method?, direction}] → 复用现有预览列表逐行确认 → 入库。
   与规则解析并列，用户自选；AI 结果行额外标「AI」。
2. 一句话记账（记一笔页顶部入口 + 批量页）：输入/语音（Speech 框架
   转文字）一句如「张三随了五百，微信」→ 解析成单笔 → 预填记一笔表单
   （不直接保存），用户核对后保存。
3. 贺词生成（礼簿详情「贺词」入口）：按事由生成——红事贺词（可用于
   礼谱封面题跋位/请柬回执）、白事挽联与唁电短文；输入主家名/与主家
   关系/口吻（庄重/亲切）；生成 3 条候选，点选可复制或写入礼谱题跋
   （v1 先到复制/展示，写进 PDF 题跋位下一版接）。

## 提示词纪律
- system 提示固定：只输出 JSON、金额一律以「元」为单位的数字、姓名
  照抄原文不猜测、拿不准的字段给 null 并在 uncertain 数组里标行号。
- 解析结果在本地再过一遍规则校验（金额>0、姓名非空），不过的行按
  失败行展示，不静默吞。
