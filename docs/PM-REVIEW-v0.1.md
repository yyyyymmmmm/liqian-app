# 产品经理评估：v0.1 对照 PRD V1.1

评估人：Muse（PM 视角） · 日期：2026-11-07 · 对象：v0.1（commit v0.1 MVP）

## 总判断

v0.1 是「链路验证版」，不是 PRD 意义上的 v1。它在单机、单人、无账号条件下走通了
UJ-01（事后记账）与 UJ-02（查人定回礼）的主干，但多处实现与 PRD 口径不一致，
且 PRD 的 v1 必做项里有整块缺失。当前版本可用于真机试用与场景验证，
不可作为 v1 交付标准。

## 逐项对照（FR 编号按 PRD）

| FR | PRD 要求 | v0.1 状态 | 差距 |
|---|---|---|---|
| FR-01.1 账本增删改/归档 | 必填事由/标题/日期，含归档 | 部分 | 无归档；删除无「提示先导出」 |
| FR-01 事由预置 | 婚礼/满月/周岁/乔迁/寿宴/升学/开业/白事/其他 | 部分 | 只有 7 类，缺满月、周岁、寿宴、开业细分 |
| FR-01.3 收随分开统计 | 账本详情两项分开 | ✓ | — |
| FR-01.5 白事克制样式 | 无红色、无喜庆词 | 基本✓ | 仅头部卡片变灰，空状态/按钮未全量检查 |
| FR-02.1 三种录入 | 单笔/连续/批量补录 | 部分 | 缺批量补录（UJ-04 纸簿搬家走不通） |
| FR-02.2 离线可记 | 本地队列+联网同步 | 变通 | 纯本地天然离线，但无账号云同步，语义未达 |

| FR-10 会员支付 | IAP 买断、恢复购买 | ✗ | 需开发者账号，后置 |
| FR-11 账号登录 | 手机号/Apple 登录、云端一致 | ✗ | 纯本地单机 |

## 阶段划分（PM 排期建议）

- v0.1 链路验证版（已交付）：证明「仓库→打包→真机」链路与核心手感。
- v0.2 口径对齐版（本轮）：不接后端，把 PRD 中纯本地可达的口径全部对齐——
  设计系统落地、未回改自动规则、待送出状态、批量补录、人物联想、
  同人提示、事由补全、搜索两组、事由分布、JSON 备份导出/导入、
  人物四要素中的「称呼+关系备注」在录入与展示层先行（合并功能后置）。
- v0.3 账号与云：登录、云同步、家庭共享三档权限（FR-07/11），需先定后端方案。
- v1.0 上架版：会员 IAP（FR-10）、PDF 礼簿导出、上架合规与封闭测试。

## 本轮不做（明确排除）

账号、云同步、家庭共享、支付、推送、拍照识别——全部后置，理由：
依赖开发者账号与后端选型，先把单机口径与设计做对，避免返工。
