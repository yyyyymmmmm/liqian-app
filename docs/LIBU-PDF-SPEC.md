# 礼谱 PDF 导出规范（产品特色，2026-11-07 用户定案）

定位：导出不是附属功能，是招牌成品。一本礼簿导出后应是一册可打印、
可留存、可传家的「数字礼谱」，式样对齐传统纸质礼簿，而不是数据表格。

## 整体式样

- 尺寸 A4；红事朱砂体系、白事素蓝体系（沿用 App 内 Palette 双态）。
- 米纸底色；朱砂细线格；竖排、右起（传统礼簿的行文方向）。
- 字体：标题与题字用楷体（iOS Kaiti SC，无则 Songti SC 回退），金额用
  中文大写数字（陆佰元整 式），正文名姓楷体竖排。

## 结构

1. 封面：朱砂（白事素蓝）满底，居中竖排题字——礼簿名（如「杨府婚礼礼谱」），
   下方小字事由、公历日期与农历日期；右下主家落款 + 朱砂印章
   （印面为礼簿题字首字/「礼」字，圆角方印白文效果）。
2. 内页：每页竖排 8 列宾客，每列自上而下：姓名（楷体大字）、金额大写、
   小字公历金额与方式（现金/微信/支付宝）与关系备注；列间朱砂细线，
   页眉小字礼簿名，页脚页码（第 X 页）。
3. 封底/汇总页：总人数、总金额（数字+大写）、按方式分布、主家落款盖印，
   下方留「校对」空行，模拟纸礼簿的手工仪式感。

## 规则

- 同人同簿两笔并列两列（不合并），与 App 口径一致。
- 白事自动素蓝、题字改克制用词（如「奠礼簿」），无描金。
- 送出方向的礼簿同样成册（封面题字如「贺仪礼谱」可由簿名直用）。
- 生成走系统 PDF 渲染（UIGraphicsPDFRenderer），离线生成，文件名
  「礼簿名-礼谱.pdf」；免费版带小字页脚「礼记 · 导出」，会员版无字样
  （与 PRD 导出分层一致，会员卖点之一）。

## 与护城河的关系

纸礼簿的仪式感+可打印留存=成品即传播：打印出来摆在家里、发到家族群，
每一本都是一次品牌露出；数据导出做成「传家礼谱」，迁移的不只是数据
是体面，这是竞品普通 CSV/表格导出给不了的。
