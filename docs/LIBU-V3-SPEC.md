# 礼谱 v3 规范（划时代礼谱·第一步：把这一本做到极致，2026-11-07 用户拍板）

在 LIBU-PDF-SPEC 基础上升级。目标：导出的不是 PDF 表格，是一册谱。

## 1. 版式：古籍版心
- A4 竖版；每页朱砂版框（外粗内细双线），版框内为版心。
- 天头留阔（约 90pt），地脚约 55pt：地脚外侧印谱名小字＋页码，居中一枚
  小鱼尾纹样（◆形变体，用路径画）呼应版心折口。
- 纸纹：宣纸底纹理（一次性生成的低透明噪点纹理图逐页平铺），白事改素纸
  无纹、版框改素蓝单线（礼制差异，不只是换色）。
- 装订暗示：右侧（竖排书自右向左，装订在右）画线装书的四眼装订点与
  两道装订线，仅封面与封底。
- 内页列数维持 8 列/页；姓名、金额大写照旧；字距放疏 1.15 倍行距感。

## 2. 干支纪年（Core 纯函数 + 单测）
- `LiqianDate.ganzhiYear(for:)`：以农历年推干支（民间礼谱口径），
  2026-11-16 → 丙午；2025-01-29 → 乙巳；2024-02-10 → 甲辰（单测断言）。
- 全谱日期统一写法：「丙午年十月初八」（干支年＋农历月日，复用 lunarString
  的月日部分），封面、谱序落款、纪年印三处一致。

## 3. 三印（按钤印规矩）
- 题字闲章（封面题字右侧）：吉语按事由——婚礼「百年好合」、寿宴「福寿
  康宁」、乔迁「乔迁之喜」、满月/周岁「平安喜乐」、升学「金榜题名」、
  开业「开业大吉」、其他「吉祥如意」；白事不用闲章（礼制）。
- 主家姓名印（封面落款处＋谱序末）：印文＝落款姓名（2–4 字，2x2 或竖列
  排布）；姓名取「礼谱落款」设置（MeView 新增，@AppStorage hostName），
  未设置时印文用「主家谨识」。
- 纪年印（封底汇总页落款旁）：印文＝干支年＋农历月（如「丙午年冬月」，
  农历十月称冬月、十一月葭月、十二月腊月、正月端月，映射表写死）。
- 印的质感：朱砂底白文，绘制时整体旋转 -1.5° 模拟手钤；以印文 hash 为
  种子的确定性微噪点（纸色小点低透明）模拟印泥不匀，同谱同印不随机变。

## 4. AI 谱序（谱序页，封面之后、内页之前）
- 导出改为 sheet 流程（礼簿详情「导出礼谱」单一入口）：选谱序文体
  （文言／白话／不用谱序）、确认落款姓名、「生成礼谱」按钮。
- 有 AI（已启用＋有 Key）：DeepSeek 生成 150–250 字谱序，素材只给事由、
  干支日期、主家名、宾客人数（不给金额明细）；文末自动落「主家 谨识」
  ＋干支日期，页上钤主家印。
- 无 AI：内置模板谱序（按事由各备一篇典雅模板，变量替换），不阻塞导出。
- 谱序页竖排右起、楷体、字号 15、列宽同内页；一页放不下自动续页。

## 5. 字体（诚实口径）
- 本版仍用 Kaiti SC（系统楷体）；方正/汉仪书法字体需商业授权＋嵌入许可，
  列为上架前商务事项，不在本版解决，样谱交付时向用户明示。
